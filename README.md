# c_webserver

> C 语言网络编程学习与工程实践项目

## 项目定位

这是一个**持续开发中的 C 语言 Web Server 项目**，用于把 C 语言基础、网络编程和工程实践逐步连接起来。

> ⚠️ 当前项目仍处于开发/完善阶段，不以“完成品”定位。仓库重点记录真实开发过程、阶段性实现与后续迭代。

## 当前定位

- 语言：C
- 方向：网络编程 / Web Server / Linux 系统编程
- 状态：🚧 持续开发中
- 目标：从基础 HTTP 服务逐步向结构清晰、可测试、可扩展的服务器工程演进

## 计划演进

```text
基础 TCP 通信
    ↓
HTTP 请求解析
    ↓
静态资源响应
    ↓
并发处理
    ↓
模块化重构
    ↓
日志 / 错误处理
    ↓
测试与性能验证
```

具体功能以代码实际实现为准，README 不提前宣称尚未完成的功能。

## 为什么保留这个项目

它与个人 C 语言文章体系形成互补：

- CSDN / CSDN 仓库：记录知识点、学习过程与技术复盘
- `c_webserver`：记录网络编程方向的实际代码工程

因此，即使当前完成度还不高，也值得保留并持续迭代。对于学习阶段项目，**真实的开发轨迹比把未完成项目包装成“成熟项目”更有价值。**

## 后续重点

1. 先保证核心功能稳定
2. 再做代码模块化
3. 增加基本测试与错误处理
4. 补充运行方式、架构说明和示例
5. 最后再考虑性能优化与更复杂的并发模型
